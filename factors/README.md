# SEMAS Alpha Factor Library

This folder contains a curated set of alpha factors discovered by the SEMAS
(Self-Evolving Multi-Agent System) factor-mining loop for China A-share CSI300
constituents.

## What is included

| File | Purpose |
|---|---|
| `expressions.json` | Factor names, DSL expressions, library grouping, and config snippets. |
| `evaluate_factors.py` | Standalone evaluator: takes a panel DataFrame and returns factor values. |
| `semas_expression.py` | DSL expression tree and evaluation logic (extracted from SEMAS). |
| `semas_parser.py` | DSL parser (extracted from SEMAS). |
| `config.yaml` | Key hyper-parameters used during evolution. |
| `example.py` | Minimal usage example. |

## Libraries

### 5-day library (`live_library.csv`)

- **Factors**: 10
- **Test Sharpe**: 2.76
- **Test cost-adjusted return**: 32.47%
- **Combined signal column**: `combined_5d`
- **Description**: Multi-horizon evolution (5d + 10d) with greedy correlation-aware selection.

### 20-day library (`live_library_20d.csv`)

- **Factors**: 2
- **20-day hold Sharpe**: 1.98
- **20-day hold cost-adjusted return**: 60.78%
- **Combined signal column**: `combined_20d`
- **Description**: Dedicated 20-day forward evolution evaluated with realistic 20-day hold backtests.

### 10-day library (`cleaned_library.csv`)

- **Factors**: 4
- **Combined signal column**: `combined_10d`
- **Description**: Temporary result from a single 10-day evolution run. **Not promoted through hold-backtest gates**; use as experimental input only.

## Quick start

```bash
pip install pandas numpy pyarrow lark
python evaluate_factors.py --data your_data.parquet --output factor_values.parquet
```

Input data requirements:

- Index: `(symbol, date)` MultiIndex, or columns `symbol` and `date`.
- Required columns: `open`, `high`, `low`, `close`, `volume`, `return`, plus any
  fundamental/money-flow columns referenced by the expressions (see
  `expressions.json`).

## Using the signals

- **Stock selection**: rank stocks by `combined_5d`, `combined_10d`, or
  `combined_20d` on the latest date and select top/bottom N.
- **ML features**: use the individual factor columns as features for supervised
  learning models.
- **Portfolio optimization**: feed the combined signals as expected-return
  inputs to an optimizer with risk constraints.

## Important caveats

1. **Historical performance is not a guarantee of future results.** All Sharpe
   ratios are in-sample or walk-forward on the test period 2024-2026.
2. **Watch for data leakage.** Ensure your data pipeline does not use future
   information when computing inputs.
3. **Transaction costs and capacity.** The 5d library has low turnover, but
   slippage, market impact, and borrow costs can erode returns.
4. **Regime change.** CSI300 constituents and market structure evolve;
   retrain/re-evaluate periodically.
5. **10d library is experimental.** It was not promoted through rigorous hold
   backtests.
